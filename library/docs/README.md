## 完成するもの

| 画面           | URL                   | できること                                                             |
| -------------- | --------------------- | ---------------------------------------------------------------------- |
| ダッシュボード | `/`                   | 蔵書数・貸出中・期限切れの数、期限切れ・期限が近い貸出、最近登録した本 |
| 本の一覧       | `/books`              | 検索・絞り込み・並び替え・ページ送り（URL に残る）、貸出・返却・削除   |
| 本の登録・編集 | `/books/new`・`/edit` | 入力チェックつきのフォーム（評価の星・タグの自由入力つき）             |
| 本の詳細       | `/books/:bookId`      | 今の貸出の状況、本の情報、貸出の履歴                                   |
| 貸出一覧       | `/loans`              | 貸出中・期限切れ・返却済み・すべて をタブで切り替え、返却              |

- 本と貸出の記録は localStorage に保存され、再読み込みしても残る
- 公開ページで動かせる：https://munakoya.github.io/react-exam-samples/library/

## 使っている技術

| 技術                        | 役割                                                                    |
| --------------------------- | ----------------------------------------------------------------------- |
| Vite ＋ React ＋ TypeScript | 開発サーバー・ビルド、画面、型                                          |
| MUI（Material UI）v9        | 見た目と部品（ボタン・入力欄・表・ダイアログ・通知など）、テーマ        |
| React Router                | URL とページの対応、URL の検索条件（`?q=…`）                            |
| Zustand（＋ persist）       | 画面をまたいで共有する状態、localStorage 保存、通知                     |
| zod                         | データの形のチェック（フォーム・保存データ）                            |
| React Hook Form             | フォームの入力・送信・エラー表示（MUI の部品とは Controller でつなぐ）  |
| FSD                         | フォルダの分け方（設計のルール）                                        |
