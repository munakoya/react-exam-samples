# 1. 始める前に決める（10 分）

> [目次](README.md) ｜ 次：[2. 雛形で環境を作る](02-start.md)

コードを書く前に 10 分だけ使う。ここで決めたことが、そのまま実装の順番と README になる。
考え方の詳しい説明は [解説書 2. 設計の考え方](../../library/docs/02-design.md)。

## やること

- [ ] 1. 要件を**チェックリストに写す**。必須と発展を分ける（README の下書きにする）
- [ ] 2. 「もの」（データ）を書き出す。項目・型・必須か・選択肢
- [ ] 3. 画面（URL）を書き出す。一覧・詳細・登録・編集のどれが要るか
- [ ] 4. 操作を書き出す。追加・編集・削除のほかに、お題固有の操作（ステータス変更・在庫の増減など）
- [ ] 5. 「保存する値」と「計算する値」を分ける
- [ ] 6. 追加・編集を**ダイアログ**にするか**ページ**にするか決める

## 書き出しの型（README にそのまま貼る）

```md
## 要件

### 必須
- [ ] 商品を追加・編集・削除できる
- [ ] 項目：名前（必須・30文字以内）、種類（食品・日用品・その他）、価格（必須・1以上）、メモ（任意）
- [ ] データを localStorage に保存する

### 発展
- [ ] 名前で検索・種類で絞り込み
- [ ] 価格で並び替え

## 設計メモ

| 画面   | URL          | できること                         |
| ------ | ------------ | ---------------------------------- |
| 一覧   | `/items`     | 表示・追加／編集（ダイアログ）・削除 |
| 詳細   | `/items/:id` | 情報・編集・削除                   |

| データ | 項目                                                  | 保存 |
| ------ | ----------------------------------------------------- | ---- |
| Item   | id・name・category（選択肢）・price・memo・createdAt・updatedAt | store（persist） |

計算する値（保存しない）：件数・合計金額・絞り込みの結果
```

## 決め方の目安

| 決めること                     | 目安                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| ダイアログ か ページ か         | 項目が 5 つくらいまで・一覧から離れたくない → **ダイアログ**。項目が多い・URL で開きたい → ページ            |
| 詳細ページは要るか             | 一覧に出しきれない情報（履歴・メモ）がある、要件に「詳細」とある → 作る。なければ作らない                   |
| 表 か カード か                 | 項目を見比べる・並び替える → **表**。画像・説明文が主役 → カード                                              |
| 保存するか                     | ユーザーが入力したもの・操作の記録 → 保存。ほかの値から求まるもの（件数・合計・期限切れか）→ **保存しない** |
| 絞り込みの条件をどこに持つか   | 再読み込み・戻るで残したい → **URL**（`useSearchParams`）。その場だけ → `useState`                           |

ほかの判断は [解説書 6-2. 迷ったときの判断基準](../../library/docs/06-thinking.md#6-2-迷ったときの判断基準)。
お題ごとにどの部品を使うかは [MUI 画面構築ガイド 6-7. お題ごとの部品の選び方](../../mui-catalog/docs/06-page-patterns.md#6-7-お題ごとの部品の選び方)。

- [ ] 実装の順番（[3. 機能を作る](03-build.md) のステップのうち、どれをやるか）が決まっている
