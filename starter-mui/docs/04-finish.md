## 1. 表示の漏れを埋める（10 分）

- [ ] 0 件のとき：一覧の代わりに `EmptyState`（追加ボタン付き）
- [ ] 条件に合うものがないとき：「条件に合うものはありません」
- [ ] 見つからないとき：存在しない id の詳細ページ・存在しない URL（404）
- [ ] 入力エラー：全部の欄に日本語のエラー文が出る。直せば送信できる
- [ ] 削除の前に確認が出る。押せないボタンには理由（`Tooltip`）
- [ ] スマホ幅（DevTools のデバイス表示で 375px）：ページ全体が横にはみ出さない。表は表の中だけでスクロール
- [ ] アイコンだけのボタンに `aria-label` がある
- [ ] キーボード：Tab で移動でき、Enter で送信、Esc でダイアログが閉じる

```bash
git commit -m "0件・見つからない場合の表示とスマホ幅の調整"
```

- [ ] 要件のチェックリストを上から試し、全部 ✓ になった（追加・編集・削除のあと**再読み込み**して残っている）

## 3. README を書く（5 分）

[1 章](01-plan.md) で貼った要件の下に足す。

```md
## 動かし方

npm install
npm run dev

## 使っている技術

React・TypeScript・Vite・MUI・React Router・Zustand（persist で localStorage に保存）・zod・React Hook Form

## フォルダの構成（FSD）

- entities：商品の型・store・カード
- features：追加・編集のダイアログ、削除（確認つき）、絞り込み
- widgets：商品の表
- pages：一覧・詳細

## できること

- 商品の追加・編集（ダイアログ）・削除（確認あり）
- …

## 工夫した点

- 件数・合計・絞り込みの結果は保存せず、表示するたびに計算している（保存したデータとずれないように）
- 追加と編集で同じフォームを使い、ダイアログを開くたびに初期値から始まるようにした
- 絞り込みの条件を URL に持たせ、再読み込みや「戻る」でも同じ表示になるようにした

## できなかった点・次にやりたいこと

- …
```

「工夫した点」は**なぜそうしたか**まで書く。

## 4. 提出する

```bash
git add -A
git commit -m "README を追加"
git push
```

- [ ] コミットが機能ごとに分かれている（`git log --oneline` で確かめる）
- [ ] `node_modules`・`dist` をコミットしていない（雛形の `.gitignore` に入っている）
- [ ] GitHub のページで README とファイルが見える
