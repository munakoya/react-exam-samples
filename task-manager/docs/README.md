## 完成するもの

| 画面   | URL      | できること                                                                       |
| ------ | -------- | -------------------------------------------------------------------------------- |
| 一覧   | `/tasks` | 追加・編集（モーダル）・削除・ステータス変更、絞り込み・並び替え、集計、期限切れ |
| ボード | `/board` | ステータスごとの 3 列で表示し、ボタンで隣の列へ動かす                            |

- データ（タスク）と表示の設定（絞り込み・並び順）は localStorage に保存され、再読み込みしても残る
- 公開ページで動かせる：https://munakoya.github.io/react-exam-samples/task-manager/

## 使っている技術

| 技術                        | 役割                                          |
| --------------------------- | --------------------------------------------- |
| Vite ＋ React ＋ TypeScript | 開発サーバー・ビルド、画面、型                |
| React Router                | URL とページの対応                            |
| Zustand（＋ persist）       | 画面をまたいで共有する状態、localStorage 保存 |
| zod                         | データの形のチェック（フォーム・保存データ）  |
| React Hook Form             | フォームの入力・送信・エラー表示              |
| CSS Modules ＋ CSS 変数     | 見た目（部品ごとの CSS、色や余白の共通値）    |
| FSD                         | フォルダの分け方（設計のルール）              |
