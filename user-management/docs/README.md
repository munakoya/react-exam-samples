# ユーザー管理アプリ 解説書（MUI 版・CRUD）

> ユーザー管理アプリ（[user-management](../)）の**すべてのファイル**について、「どこに・何を書いているか」と「なぜそこに書くのか」を説明する。
> 読み終えたら、同じアプリを**何も見ずに迷わず作れる**ことがゴール。
> MUI・zod・Zustand・React Hook Form・React Router の基本は [蔵書管理の解説書](../../library/docs/README.md) にまとめてある。この解説書は「このアプリのコードを読み解く」ことに絞っている。

自分で作るときは 6 を開いて、手が止まったら 2〜4 の該当ファイルの説明と 7 を見る。

## 完成するもの

| URL          | 画面 | できること                                                                                                       |
| ------------ | ---- | ---------------------------------------------------------------------------------------------------------------- |
| `/`          | ―    | `/users` へ移動する                                                                                              |
| `/users`     | 一覧 | 表／カードの切り替え、検索・権限で絞り込み（URL に残る）、追加・編集ダイアログ、削除の確認、チェックで一括操作 |
| `/users/:id` | 詳細 | ユーザーの情報、編集ダイアログ、削除（削除したら一覧へ戻る）                                                     |
| それ以外     | 404  | 「ページが見つかりません」と一覧へのリンク                                                                       |

- データは localStorage（キー `user-management:users`）に保存され、再読み込みしても残る
- 最初から 6 人分のデータが入っている

## このアプリで覚える「CRUD の型」

このアプリは、試験でよく出る CRUD の UI を 1 つずつ入れてある。どれも別のお題にそのまま持っていける。

| UI                                       | 書いている場所                                                           | 章                                        |
| ---------------------------------------- | ------------------------------------------------------------------------ | ----------------------------------------- |
| 追加ボタン → 追加ダイアログ              | `pages/user-list` ＋ `features/user-form` ＋ `shared/ui/useFormDialog`   | [3](03-entities-features.md)・[4](04-widgets-pages.md) |
| 行・カードの編集ボタン → 編集ダイアログ  | 同じダイアログを使い回す（`dialog.openEdit(user)`）                      | [4](04-widgets-pages.md)                  |
| 削除ボタン → 確認ダイアログ              | `features/delete-user` ＋ `shared/ui/ConfirmDialog`                      | [3](03-entities-features.md)              |
| チェックボックスで選ぶ表 → 一括操作      | `widgets/user-table` ＋ `shared/ui/DataTable`                            | [2](02-app-shared.md)・[4](04-widgets-pages.md) |
| 表の中のスイッチで即時切り替え           | `features/change-user-status`                                            | [3](03-entities-features.md)              |
| 検索・絞り込みを URL に持つ              | `features/user-filter`                                                   | [3](03-entities-features.md)              |
| 表とカードの切り替え                     | `pages/user-list`（`?view=card`）＋ `widgets/user-card-grid`             | [4](04-widgets-pages.md)                  |
| 重複チェックつきの入力チェック           | `features/user-form/model/schema.ts`                                     | [3](03-entities-features.md)              |
| 操作のあとの通知（スナックバー）         | `shared/ui/Notifier`（`notify("…")`）                                    | [2](02-app-shared.md)                     |

## 使っている技術

| 技術                        | このアプリでの役割                                                   |
| --------------------------- | -------------------------------------------------------------------- |
| Vite ＋ React ＋ TypeScript | 開発サーバー・ビルド、画面、型                                       |
| MUI（Material UI）v9        | 部品（表・ダイアログ・Chip・Switch・Snackbar など）とテーマ          |
| React Router                | `/users`・`/users/:id` の切り替え、URL の検索条件（`?q=` など）       |
| Zustand（＋ persist）       | ユーザー一覧の共有と localStorage 保存、通知                         |
| zod                         | フォームの入力チェック、保存データの形のチェック                     |
| React Hook Form             | ダイアログのフォームの入力・送信・エラー表示                         |
| FSD（Feature-Sliced Design）| フォルダの分け方（app / pages / widgets / features / entities / shared） |
